## Lessons Learned

Proven patterns and anti-patterns. Reference during implementation.

### What Worked

<!-- Max 15 items -->

1. **Ephemeral token pattern**: Backend generates short-lived tokens for WebSocket auth (OpenAI, xAI)
2. **Provider-specific contexts**: Separate state management per provider prevents coupling
3. **useReconnection hook**: Centralized reconnection logic with exponential backoff
4. **Component composition**: VoiceButton, VoiceStatus, VoiceVisualizer reused across providers
5. **Environment variable toggles**: VITE\_\*\_ENABLED flags control provider visibility

### What to Avoid

<!-- Max 10 items -->

1. **Hardcoded API keys**: Never in frontend code - always use backend proxy or public tokens
2. **Shared WebSocket state**: Each provider needs isolated connection management
3. **Over-abstraction**: Provider-specific quirks mean some duplication is acceptable

### Tool/Library Notes

<!-- Max 5 items -->

1. **@elevenlabs/react**: Use useConversation hook for SDK mode
2. **retell-client-js-sdk**: Uses LiveKit internally; SDK only provides last 5 transcript sentences
3. **@vapi-ai/web**: Frontend-safe with public web token; no backend required
